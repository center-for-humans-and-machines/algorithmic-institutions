The group copula: herding for the Gaussian sampler

correlated-sampling installed by PR #170 · contribution bay of the gaussian-MLP machine

The problem

The same herding gap as on the gnn machine: independent per-member draws kept the group averages huddled together, and on this stack the group-spread row (CG) also sat in the worst band, above 5.

The change

A cousin of the gnn machine's herding copula (PR #165), rebuilt for this trunk's continuous sampler rather than ported: each member's Gaussian noise is mixed from three parts -- their own noise, a group component drawn once per episode, and a group component drawn fresh each round. The blend is scaled so each member's own distribution is exactly preserved. It earns its own page because the persistence mechanics differ: episode-level plus round-level shared components here, an AR(1) chain there.

The maths, in plain English

  1. This stack's contribution model outputs a bell curve per member -- a centre mu and a spread sigma -- and samples 'mu + sigma x z', where z is a fresh standard bell-curve draw. So here the coupling goes directly into z, no percentile conversion needed.
  2. Build each member's z from three ingredients: u = one draw per group per EPISODE (the lasting mood), v = one draw per group per ROUND (the momentary one), and e = the member's private draw. Blend: z = sqrt(rho_p) x u + sqrt(rho_t) x v + sqrt(1 - rho_p - rho_t) x e. The three weights squared sum to 1, so z is again a perfect single bell-curve draw and every member's own curve N(mu, sigma) is untouched.
  3. Fitting: replay the real games with the model watching and turn every actual contribution into a z-score against the model's own prediction -- (actual - mu) / sigma.
  4. Two questions, two dials. How strongly do groupmates' z-scores agree within one round? That pins the TOTAL shared part, rho_p + rho_t. How much of that agreement is still there when you compare different rounds of the same episode? Only the episode mood survives across rounds, so that pins rho_p by itself. Both answers by maximum likelihood on training data.
  5. Where it plugs in: at the sampling step of the simulation, gated by two numbers stored on the model file (rho_p, rho_t). Both at 0 reproduces the old independent draws exactly, down to the random-number stream.

Where it lives in the code

  • src/aimanager/simulation/linear_ah.py — the three-part blend, gated by copula_rho_p / copula_rho_t on the bundle; both 0 restores the independent path and its exact RNG stream
  • scripts/baselines/contribution_gmlp_copula_rho.py — estimates rho_p and rho_t from teacher-forced z-scores
  • scripts/baselines/stamp_contribution_group_copula.py — stamps the two fields onto the .joblib bundle

(paths as changed on PR #170)

What it bought

CG 5.91 -> 2.83 and a band upgrade on CA (each participant's average contribution); the stack mean fell 1.61 -> 1.31.
