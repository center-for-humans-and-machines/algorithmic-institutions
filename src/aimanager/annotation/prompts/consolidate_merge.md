# Task: merge codes within families to reach the target size

Below is a codebook of $n_codes codes, listed under their families. $kind_text It should have about $target codes; $level

Merge codes within each family that are the same kind of thing at that level: variants that differ only in a threshold, a constant, the exact formula or a detail of the same idea become one code. Merge only codes that fit the level above equally well, and never merge codes that refer to different things a rule conditions on or acts on. $kind_rules

For each merge give the codes it joins (`codes`, at least two, usually from one family), the `reason` why they are one code at this level (one sentence), the name that survives (`keep`, one of them), and a `label` and rewritten `definition` that covers all of them. Leave `merges` empty if no codes should be merged.
