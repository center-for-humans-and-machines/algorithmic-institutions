# Reward Timing and Temporal Credit Assignment in RL

## Research question

Does the timing of reward attribution (same-round vs. next-round) matter for RL training when using undiscounted returns (gamma=1)? Specifically, does including the next round's contributions in the manager's reward for the current round affect learning dynamics, convergence, or policy quality?

This review was prompted by [issue #40](https://github.com/center-for-humans-and-machines/algorithmic-institutions/issues/40), which proposes aligning the reward so it reflects only the round in which the manager acts.

## Key findings

- **Under gamma=1 and fixed-length episodes, shifting reward timing by one step does not change the total undiscounted return.** This is a well-established property of the return definition. The claim in the issue is correct on this point.
- **However, reward timing can meaningfully affect learning dynamics** even when the total return is unchanged. Temporal difference methods (DQN, SARSA) learn per-step value estimates, and shifting rewards changes the variance and bias of bootstrapped targets at each step.
- **Potential-based reward shaping** (Ng et al., 1999) provides the formal framework for understanding when reward transformations preserve optimal policies. A one-step reward shift is not a potential-based transformation in general, so policy invariance is not formally guaranteed.
- **Delayed rewards are a known challenge** in RL. Empirical work shows that more immediate, temporally-aligned rewards tend to produce faster and more stable learning, even when total returns are equivalent.
- **In social dilemma / public goods game settings**, the literature does not prescribe a single reward timing convention, but the dominant approach is to define the institution's reward based on the outcome of the current period.

## Papers

### Sutton & Barto (2018). *Reinforcement Learning: An Introduction* (2nd ed.). MIT Press.

**Relevance**: Foundational RL textbook defining the standard reward timing convention.

The standard MDP formulation defines r_{t+1} as the reward received after taking action a_t in state s_t. Crucially, this reward is generated by the transition from s_t to s_{t+1} -- it reflects the immediate consequence of the action, not future consequences. The return G_t = sum of r_{t+1} + r_{t+2} + ... captures future consequences through the recursive Bellman structure. When gamma=1 and the episode length is fixed, the total return G_0 is invariant to a constant temporal shift of rewards, since it is just a reindexing of the same sum. However, the per-step Q-value targets Q(s_t, a_t) = r_{t+1} + gamma * max Q(s_{t+1}, a) are directly affected by which reward is attributed to each step. This means TD learning dynamics (update magnitudes, variance of targets) can differ even when the total return does not.

### Ng, Harada, & Russell (1999). "Policy invariance under reward transformations: Theory and application to reward shaping." *ICML*.

**Relevance**: Establishes conditions under which modifying the reward function preserves optimal policies.

This paper proves that adding a potential-based shaping function F(s, s') = gamma * Phi(s') - Phi(s) to the reward preserves the set of optimal policies. This is the canonical result for understanding when reward modifications are "safe." A one-step temporal shift of rewards (attributing r_{t+1} to step t instead of step t+1) is generally *not* expressible as a potential-based shaping function, because the shifted reward depends on the action taken and the resulting state transition, not just on a state potential. Therefore, the formal guarantee of policy invariance does not apply to the reward shift described in issue #40. In practice, with gamma=1 and fixed episode length, the optimal policy is likely the same (since the same total reward is achievable), but the learning path may differ.

### Devlin & Kudenko (2012). "Dynamic potential-based reward shaping." *AAMAS*.

**Relevance**: Extends potential-based shaping to non-stationary settings.

This work generalizes Ng et al. to allow the potential function to change over time, which is relevant to finite-horizon episodic tasks like the public goods game. The key insight is that even in episodic settings with changing dynamics, potential-based shaping preserves optimal policies. This provides additional confidence that if the reward shift in question *could* be expressed as a potential-based transformation, policy invariance would hold. However, the temporal shift in issue #40 remains outside this framework for the reasons discussed above.

### Arjona-Medina et al. (2019). "RUDDER: Return Decomposition for Delayed Rewards." *NeurIPS*.

**Relevance**: Directly addresses the problem of delayed rewards and temporal credit assignment.

RUDDER demonstrates that delayed rewards (rewards that arrive many steps after the causally relevant action) significantly slow down learning in practice, even when the total return is unchanged. The paper proposes decomposing the return into per-step reward contributions that are more temporally aligned with the actions that caused them. This is directly relevant: the current implementation in this project gives the manager a reward that includes next-round contributions (a form of lookahead), while the proposed change would make the reward more immediate. RUDDER's analysis suggests that more temporally aligned rewards generally improve learning, supporting the proposed change in the issue. However, the effect size depends on the horizon and the degree of delay -- a one-step shift in a short episode (the public goods game typically has 10 rounds) may have minimal practical impact.

### Laud (2004). "Theory and Application of Reward Shaping in Reinforcement Learning." PhD thesis, UIUC.

**Relevance**: Comprehensive treatment of reward shaping theory and practice.

Laud's thesis provides both theoretical analysis and empirical evidence that the temporal structure of rewards affects learning speed even when optimal policies are preserved. Key finding: rewards that are more tightly coupled to the action that caused them lead to faster convergence in Q-learning and related algorithms. This is because the variance of the TD error is reduced when rewards are temporally aligned -- the bootstrapped target has less "noise" from confounding future events. For the one-step shift in issue #40, this suggests a modest improvement in learning stability, though the effect may be small given the short episode length.

### Leibo et al. (2017). "Multi-agent Reinforcement Learning in Sequential Social Dilemmas." *AAMAS*.

**Relevance**: Multi-agent RL in social dilemma settings, including reward design considerations.

This paper studies RL agents in social dilemma games (prisoner's dilemma, stag hunt). The reward for each agent is defined as the payoff from the current timestep, following the standard convention. There is no lookahead component. This supports the proposed change: the standard practice in multi-agent social dilemma research is to use contemporaneous rewards.

### Hughes et al. (2018). "Inequity Aversion Improves Cooperation in Intertemporal Social Dilemmas." *ICML*.

**Relevance**: RL agents with modified reward functions in social dilemma settings.

Hughes et al. augment the reward function with inequity aversion terms but maintain the convention that the reward at step t reflects the outcome at step t. The modified reward components (envy, guilt) are computed from the current step's payoff distribution. This further supports the convention of temporally-aligned rewards in social dilemma research.

### Vinitsky et al. (2023). "A learning agent that acquires social norms from public sanctions in decentralized multi-agent environments." *PNAS*.

**Relevance**: Institutional/sanctioning agents in public goods-like settings.

This paper studies how sanctioning mechanisms (analogous to the manager's punishment in this project) affect agent behavior. The sanctioning agent's reward is based on the current period's social welfare measure. The causal effect of sanctions on future behavior is captured through the RL training process itself (via the Bellman equation and temporal discounting), not by folding future outcomes into the current reward. This aligns with the proposed change and represents current best practice.

### Fehr & Gachter (2000). "Cooperation and Punishment in Public Goods Experiments." *American Economic Review*.

**Relevance**: Foundational experimental economics paper on punishment in public goods games.

While not an RL paper, this work establishes the empirical setup that this project models. In the experimental framework, outcomes are measured per round: a punishment decision in round t affects payoffs in round t, and behavioral responses (changed contributions) appear in round t+1. The economics convention treats these as separate outcomes in separate periods. This supports defining the manager's reward based on round-t outcomes only.

## Synthesis

The issue's claims are largely supported by the literature, with some important nuances:

**Claim 1 (standard RL convention)**: Correct. The standard MDP formulation attributes rewards to the transition that generated them. Including next-round contributions in the current reward deviates from this convention (Sutton & Barto, 2018).

**Claim 2 (richer causal signal)**: Plausible but not well-supported as a design choice. The RL literature (RUDDER, Laud) suggests that folding future outcomes into current rewards does not generally help learning -- the Bellman equation already handles temporal credit assignment. The "richer signal" intuition conflates two things: (a) the causal link between punishment and future contributions, which the Q-function learns through bootstrapping, and (b) the reward signal itself, which should reflect the immediate outcome.

**Claim 3 (no advantage without discounting)**: Partially correct but incomplete. With gamma=1, there is no discounting penalty for delayed information, so the lookahead does not provide a mathematical optimization advantage in terms of total return. However, the learning dynamics argument is separate from the optimization argument -- even with gamma=1, reward timing affects TD target variance and convergence speed.

**Claim 4 (total return unchanged)**: Correct for fixed-length episodes with gamma=1. The sum of rewards over the episode is the same regardless of the one-step shift. This is a straightforward consequence of the telescoping sum.

**Claim 5 (Q-value targets change slightly but aggregate signal equivalent)**: Correct in spirit but understates the potential impact on learning dynamics. While the optimal policy is almost certainly the same, the per-step TD targets will differ, and this can affect convergence speed and stability (Laud, 2004; Arjona-Medina et al., 2019). For a 10-round episode with a one-step shift, the practical effect is likely small but not zero.

**Overall assessment**: The proposed change is well-motivated and aligns with standard conventions in both the RL and experimental economics literatures. The risk of changing training outcomes is low. The primary benefit is conceptual clarity and alignment with community norms, which matters for a research project where the reward function is part of the scientific contribution.

## Open questions

1. **Empirical verification**: Has anyone systematically measured the effect of one-step reward shifts on DQN convergence in short-horizon episodic tasks? The theoretical arguments suggest small effects, but empirical confirmation in this specific setting would be valuable.

2. **Boundary effects**: The current implementation handles the final round differently (using only punishment cost when done=True). The proposed change would need to handle both the first and last rounds carefully. The literature on episodic reward shaping (Devlin & Kudenko, 2012) provides guidance but specific boundary conditions need case-by-case analysis.

3. **Interaction with replay memory**: The DQN implementation uses experience replay. Reward timing interacts with how transitions are stored and sampled. It would be worth verifying that the replay memory correctly pairs (s_t, a_t, r_t, s_{t+1}) after the change.

4. **Discount factor sensitivity**: The current implementation uses gamma=1, but if future work introduces discounting, the reward timing would become more consequential. Aligning rewards now makes the codebase more robust to such changes.
